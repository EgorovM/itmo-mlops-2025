# Отчет по домашнему заданию 5: API для моделей машинного обучения

## Обзор

В данной работе был развернут сервис для инференса моделей машинного обучения с использованием Triton Inference Server. Было протестировано две модели для классификации выживших на Титанике.

## Архитектура

- **Фреймворк**: Triton Inference Server
- **Backend**: Python
- **Контейнеризация**: Docker + Docker Compose
- **Порты**: 8080 (HTTP), 8081 (gRPC), 8082 (метрики)

## Тестируемые модели

1. **titanic_logistic_regression** - Логистическая регрессия
2. **titanic_random_forest** - Случайный лес

*Примечание: Модель titanic_gradient_boosting была исключена из тестирования из-за несовместимости версий scikit-learn (модель обучена на версии 1.5.1, а контейнер использует версию 1.7.0).*

## Результаты тестирования качества

Тестирование проводилось на валидационном наборе данных (181 образец):

| Модель | Accuracy | Precision | Recall | F1 Score |
|--------|----------|-----------|--------|----------|
| titanic_logistic_regression | 0.8101 | 0.7966 | 0.6812 | 0.7344 |
| titanic_random_forest | 0.8045 | 0.7931 | 0.6667 | 0.7244 |

### Выводы по качеству:
- Логистическая регрессия показала немного лучшие результаты по всем метрикам
- Обе модели достигли приемлемого уровня точности (>80%)
- F1-score обеих моделей находится в диапазоне 0.72-0.73

## Результаты тестирования производительности

Тестирование проводилось с 50 запросами для каждой модели:

| Модель | Throughput (RPS) | Avg Latency (ms) | P95 Latency (ms) | Success Rate |
|--------|------------------|------------------|------------------|--------------|
| titanic_logistic_regression | 401.32 | 2.49 | 2.50 | 100% |
| titanic_random_forest | 207.17 | 4.83 | 6.58 | 100% |

### Выводы по производительности:
- **Логистическая регрессия** демонстрирует превосходную производительность:
  - В ~2 раза выше пропускная способность (401 vs 207 RPS)
  - В ~2 раза меньше задержка (2.49 vs 4.83 ms)
  - Более стабильная латентность (P95: 2.50 vs 6.58 ms)

- **Случайный лес** показывает более высокую вычислительную сложность:
  - Меньшая пропускная способность из-за необходимости обработки множества деревьев
  - Большая вариативность времени отклика

## Рекомендации

1. **Для продакшена**: Рекомендуется использовать **логистическую регрессию** как основную модель благодаря:
   - Лучшему качеству предсказаний
   - Значительно более высокой производительности
   - Более стабильному времени отклика

2. **Для улучшения**:
   - Перетренировать модель gradient_boosting с совместимой версией scikit-learn
   - Рассмотреть возможность квантизации моделей для дальнейшего ускорения
   - Добавить мониторинг метрик в реальном времени

## Техническая информация

- **Окружение**: Docker контейнер с Triton Server 23.12
