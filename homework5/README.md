# Домашнее задание 5: API для моделей

В этом задании мы разворачиваем сервис для инференса моделей с помощью Triton Inference Server.
Мы будем использовать три модели для классификации выживших на Титанике.

## Структура

- `models/`: Репозиторий моделей для Triton.
  - `titanic_logistic_regression/`: Модель логистической регрессии.
  - `titanic_gradient_boosting/`: Модель градиентного бустинга.
  - `titanic_random_forest/`: Модель случайного леса.
  - `config.pbtxt`: Конфигурация модели для Triton.
  - `1/model.pkl`: Файл с сериализованной моделью.
  - `1/model.py`: Скрипт для выполнения инференса модели на Python бэкенде.
- `docker-compose.yaml`: Файл для запуска Triton сервера.
- `Dockerfile`: Кастомный образ Triton с установленными зависимостями.
- `client.py`: Скрипт для отправки запросов к серверу и оценки качества моделей.
- `simple_perf_test.py`: Скрипт для тестирования производительности моделей.
- `performance_analyzer.py`: Расширенный анализатор производительности (с поддержкой конкурентности).
- `requirements.txt`: Зависимости для клиентских скриптов.
- `report.csv`: Отчет с результатами качества моделей.
- `performance_report.csv`: Отчет с результатами производительности моделей.
- `final_report.md`: Итоговый отчет с полным анализом результатов.

## Как запустить

1. **Установите Docker и Docker Compose**

2. **Соберите и запустите контейнер:**
   ```bash
   docker-compose up --build -d
   ```

3. **Дождитесь запуска сервера** (проверьте логи):
   ```bash
   docker-compose logs triton
   ```

4. **Установите зависимости для клиента:**
   ```bash
   pip install -r requirements.txt
   ```

5. **Запустите тестирование качества:**
   ```bash
   python client.py
   ```

6. **Запустите тестирование производительности:**
   ```bash
   python simple_perf_test.py
   ```

## Результаты

После выполнения тестов будут созданы файлы:
- `report.csv` - метрики качества моделей
- `performance_report.csv` - метрики производительности
- `final_report.md` - итоговый анализ

## Технические детали

- **Сервер**: Triton Inference Server 23.12
- **Порты**: 8080 (HTTP), 8081 (gRPC), 8082 (метрики)
- **Backend**: Python с поддержкой scikit-learn
- **Модели**: Логистическая регрессия и случайный лес для классификации Titanic

## Конфигурация моделей

Каждая модель имеет файл конфигурации `config.pbtxt`, который определяет:
- Имя модели
- Тип backend'а (python)
- Входные тензоры (10 признаков, тип FP32)
- Выходные тензоры (предсказания, тип INT64)
- Конфигурация экземпляров (CPU)

## Остановка сервиса

```bash
docker-compose down
```
